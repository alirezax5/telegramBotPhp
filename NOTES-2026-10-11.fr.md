### 1. Méthodes Managed Bots — contrats d'API en direct (prouvés)
- `request_managed_bot` → `request_id` doit être un **int**. Une chaîne échoue avec
  `Bad Request: Field "request_id" must be a valid Number` (« request_id » doit être un
  nombre valide). Conservez l'indication de type `int` ; documentez-la.
- `getManagedBotToken(int $botId)` → renvoie un jeton de bot enfant en direct. Avec un
  identifiant d'utilisateur humain, il renvoie `Bad Request: user is not a bot`
  (« l'utilisateur n'est pas un bot » ; réponse réelle capturée).
- Chaîne complète prouvée en direct : `request_managed_bot` (bouton clavier,
  request_id=1001) → l'utilisateur accepte → update `managed_bot`
  `{user: <human>, bot: <child>}` → `getManagedBotToken(bot.id)` → `getMe` de l'enfant ✔ →
  `sendMessage` de l'enfant livré.
- Également atteignables, avec des erreurs propres (en direct) :
  `answerChatJoinRequestQuery`, `answerGuestQuery` (`QUERY_ID_EMPTY` si vide),
  `getBusinessConnection`, `message_thread_id` en chat privé
  (`message thread not found` « fil de discussion introuvable », conditionné par
  `has_topics_enabled`).

### 2. Transport du jeton — le seul modèle correct (prouvé 8/8)
- Le jeton du bot ne voyage QUE dans le chemin d'URL `/bot<token>/METHOD`. Toutes les
  variantes d'en-tête (Authorization: Bearer, X-Telegram-Bot-Api-Secret-Token, X-Bot-Token,
  Bot) avec un jeton de chemin erroné/absent → 401/404. Jeton dans la chaîne de requête ou
  le corps JSON → rejeté. N'ajoutez pas de transport de jeton par en-tête.
- Telegram→votre-webhook transporte `X-Telegram-Bot-Api-Secret-Token` = le secret que VOUS
  définissez dans `setWebhook` (clé de routage par bot), jamais le jeton du bot.

### 3. Routage webhook multi-bots par secret_token (prouvé 7/7)
- Deux bots, UN seul fichier webhook, des `secret_token` distincts — identité toujours
  correcte (branches message + callback_query, trafic réel). L'exemple de routeur minimal
  se trouve dans `docs/en/guides/multi-bot.md` (et 6 autres langues).
- `webhook.php` pour les fermes multi-bots : validez `X-Telegram-Bot-Api-Secret-Token`
  avec `hash_equals()`, routez vers le jeton du bot correspondant depuis le registre,
  403 pour les secrets inconnus.
