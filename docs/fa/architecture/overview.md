# نمای کلی پروژه

**telegramBotPhp** یک پوشش (wrapper) سبک و بدون وابستگی برای Telegram Bot API روی PHP 8.1+ است.

## هدف

در معرض گذاشتن تمام متدهای Telegram Bot API از طریق یک سطح شیءگرا و ارگونومیک در PHP، در حالی که پیش‌نیازهای زمان اجرا کمینه باقی می‌ماند (فقط PHP + cURL — بدون پکیج خارجی، بدون فریم‌ورک).

## دامنه و اعداد

| سنجه | مقدار |
|--------|-------|
| متدهای Bot API پوشش‌داده‌شده | **186** |
| کلاس‌های تایپ‌شده پاسخ/موجودیت | **199** |
| نسخه PHP | >= 8.1 |
| وابستگی‌های زمان اجرا | **0** (از `ext-curl` و `ext-json` استفاده می‌کند) |
| سبک داده | بارگذاری خودکار PSR-4؛ رمزگشایی `stdClass` + پوشش‌های تایپ‌شده تنبل |

## گسترش API

پوشش (wrapper) هر اندپوینت را به یک **متد** روی `Telegram` نگاشت می‌کند (که از طریق *تریت‌های* دامنه‌ای مخلوط می‌شود) و هر پاسخ/موجودیت JSON را به یک کلاس **تایپ** زیر `src/Types/` نگاشت می‌کند.

## اهداف طراحی

1. **کامل بودن** — همگام ماندن با Bot API رسمی در `https://core.telegram.org/bots/api`.
2. **ارگونومی** — گترهای دوستانه (`text()`، `chatId()`، `mediaType()`) روی شیءهای خام.
3. **قابلیت اطمینان** — retry داخلی HTTP با backoff نمایی + مدیریت `retry_after`، هندل cURL قابل استفاده مجدد، پشتیبانی از timeout پالس طولانی.
4. **قفل‌شدگی صفر** — بدون وابستگی به فریم‌ورک؛ قابل استفاده از اسکریپت‌های وبهوک یا long-polling.

چیدمان را در [folder-structure.md](folder-structure.md)، سطح API را در [methods.md](methods.md) و کلاس اصلی را در [telegram-class.md](telegram-class.md) ببینید.
