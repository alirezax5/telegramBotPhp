# نظرة عامة على المشروع

**telegramBotPhp** هو غلاف خفيف الوزن خالٍ من الاعتماديات الخارجية لـ Telegram Bot API يعمل مع PHP 8.1+ فأحدث.

## الغرض

كشف كل أسلوب من أساليب Telegram Bot API من خلال واجهة PHP كائنية التوجه مريحة الاستخدام، مع الإبقاء على البيئة التشغيلية في حدها الأدنى (PHP + cURL فقط — لا حزم خارجية ولا إطار عمل).

## النطاق والأرقام

| المقياس | القيمة |
|--------|-------|
| أساليب Bot API المشمولة | **186** |
| أصناف الاستجابات/الكيانات الممنوهة بالأنواع | **199** |
| إصدار PHP | >= 8.1 |
| اعتماديات التشغيل | **0** (يستخدم `ext-curl`، `ext-json`) |
| أسلوب البيانات | تحميل تلقائي وفق PSR-4؛ فك ترميز إلى `stdClass` + أغلفة ممنوهة بالأنواع بشكل كسول |

## توسعة الـ API

يربط الغلاف كل نقطة نهاية (endpoint) بـ**أسلوب** على الصنف `Telegram` (يُمزج عبر *traits* خاصة بالمجالات)، وكل استجابة/كيان JSON بصنف **نوع** ضمن `src/Types/`.

## أهداف التصميم

1. **الاكتمال** — البقاء متزامنًا مع Bot API الرسمي على `https://core.telegram.org/bots/api`.
2. **سهولة الاستخدام** — دوال وصول (getters) ودّية مثل `text()` و`chatId()` و`mediaType()` فوق الكائنات الخام.
3. **الموثوقية** — إعادة محاولة HTTP مدمجة مع تراجع أُسّي + معالجة `retry_after`، ومقبض cURL قابل لإعادة الاستخدام، ودعم مهلة الاستطلاع الطويل.
4. **انعدام الارتباط** — لا اعتماديات على أي إطار عمل؛ قابل للاستخدام من سكربتات ويب هوك أو من سكربتات الاستطلاع الطويل.
