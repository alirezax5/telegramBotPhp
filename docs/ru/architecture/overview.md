# Обзор проекта

**telegramBotPhp** — это лёгкая обёртка для Telegram Bot API на PHP 8.1+ без внешних зависимостей.

## Назначение

Предоставить доступ к каждому методу Telegram Bot API через эргономичный объектно-ориентированный PHP-интерфейс, сохраняя минимальное окружение времени выполнения (только PHP + cURL — никаких внешних пакетов, никаких фреймворков).

## Объём и цифры

| Метрика | Значение |
|---------|----------|
| Покрытые методы Bot API | **186** |
| Типизированные классы ответов/сущностей | **199** |
| Версия PHP | >= 8.1 |
| Зависимости времени выполнения | **0** (используются `ext-curl`, `ext-json`) |
| Стиль работы с данными | автозагрузка PSR-4; декодирование в `stdClass` + ленивые типизированные обёртки |

## Расширение API

Обёртка отображает каждый эндпоинт в **метод** класса `Telegram` (подмешиваемый через доменные *трейты*), а каждый JSON-ответ/сущность — в **класс-тип** в `src/Types/`.

## Цели проектирования

1. **Полнота** — поддерживаться в синхроне с официальным Bot API по адресу `https://core.telegram.org/bots/api`.
2. **Эргономичность** — дружелюбные геттеры (`text()`, `chatId()`, `mediaType()`) поверх «сырых» объектов.
3. **Надёжность** — встроенные повторы HTTP с экспоненциальной задержкой + обработка `retry_after`, переиспользуемый дескриптор cURL, поддержка тайм-аута long polling.
4. **Нулевая привязка** — никаких зависимостей от фреймворков; можно использовать из скриптов вебхука или long polling.
